お知らせ

  • 2026-05-27 — デザインを刷新し、動作しなくなったデモを整理しました。多言語対応(日本語 / 英語)を追加。
  • 2026-05-27 — SPARQLエンドポイント(sparql.dl.itc.u-tokyo.ac.jp)とSnorqlの停止に伴い、依存していたデモを撤去しました。puzzleはIIIFのみで動作するように、timelineは静的データで動作するように再構成しました。
サービス停止のお知らせ: 以前提供していたSPARQLエンドポイントとSnorqlは停止しています。これらに依存していた可視化デモ(calendar / map / matrix / providers / freq など)はリポジトリから整理しました。 履歴は git log から参照できます。
